# 雨课堂课程助手

一个运行在 [雨课堂网页版](https://pro.yuketang.cn/) 的 Tampermonkey 用户脚本，用于下载课程课件和录播，并提供可选的课堂答题辅助。

当前脚本版本为 **1.3.0**。运行时只需要 [`main.js`](main.js)，不依赖其他脚本库、Node.js 或 npm。

## 功能

- **课件下载**：识别课堂加载的课件接口，抓取课件图片并在浏览器中合成为 PDF。
- **录播下载**：识别雨课堂录播地址，支持 HTTP Range 分段下载、进度显示、失败重试和单连接回退。
- **手动确认**：捕获到的课件和录播会先进入列表，由用户勾选后统一下载。
- **统一下载面板**：顶层页面只显示一个面板，支持桌面拖动、手机竖屏、最小化、关闭和悬浮按钮恢复。
- **跨标签页资源列表**：同源标签页会同步资源元数据，各标签页保留自己的勾选状态。
- **保存确认**：只有收到 Tampermonkey 保存成功回调，或“另存为”成功写入并关闭后，才计入已保存。
- **失败恢复**：网络下载失败的项目会回到列表；自动保存失败时保留已生成的 PDF/MP4，可直接重试或另存为。
- **安全恢复**：刷新后保留课件和录播的恢复信息，不持久化课堂 Cookie、认证请求头或带签名的资源 URL。
- **可选答题辅助**：默认关闭，支持随机选择并提交、AI 回答后自动提交、AI 仅显示回答三种模式。

## 安装

### 1. 安装 Tampermonkey

请在受支持的浏览器中安装 Tampermonkey：

- [Chrome 版](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- [Edge 版](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
- [Firefox 版](https://addons.mozilla.org/firefox/addon/tampermonkey/)

### 2. 安装脚本

在 Tampermonkey 中新建用户脚本，将 [`main.js`](main.js) 的完整内容粘贴到编辑器中并保存；也可以直接导入该文件。安装本项目不需要安装其他脚本库或额外依赖。

脚本需要完整保留 `main.js` 顶部的 `// ==UserScript==` 元数据，尤其是 `@match`、`@grant` 和 `@connect` 字段。

### 3. 配置下载权限

在 Tampermonkey 设置中将下载模式设为 **浏览器 API（Browser API）**，按浏览器提示授予下载权限，并允许 `pdf` 和 `mp4` 扩展名。

保存功能依赖 [`GM_download`](https://www.tampermonkey.net/documentation.php?locale=en&q=GM_download)。如果浏览器不支持文件保存选择器，“另存为”可能不可用，此时请修正 Tampermonkey 下载权限后使用“重试保存”。

### 4. 打开雨课堂

登录 [雨课堂网页版](https://pro.yuketang.cn/) 并进入课程页后，页面右下角会自动显示“雨课堂助手”。

### 更新脚本

将新版 `main.js` 完整覆盖到现有用户脚本中并保存，然后刷新最外层课程页。不要同时启用本项目的两个版本；旧版本已经生成的待保存文件不会由新版接管。

## 下载课件与录播

1. 进入课程并打开课件，或打开需要下载的录播。
2. 等待资源出现在“课件与录播”列表。
3. 勾选需要保存的项目，点击“下载选中”。
4. 课件会生成 PDF，录播会保存为 MP4。
5. 在“待保存文件”区域确认保存结果。

脚本不会自动打开下载的文件，也不会把服务器返回的内容作为程序执行。输出类型固定为 PDF 或 MP4。

### 待保存文件

“待保存文件”只保存在当前页面内存中。出现该区域时，请先完成导出，再刷新或关闭标签页。页面离开提醒不能防止浏览器崩溃、强制结束进程或页面被回收。

保存超时后请先检查浏览器下载记录，避免重复导出。关闭面板、清空下载列表或清除采集记录都不会删除当前页面中尚未保存的文件。

### 刷新后的恢复

- 课件会尝试使用当前登录会话重新获取，因此通常可以在刷新后继续下载。
- 录播的授权地址可能短期过期。刷新或重新进入页面后，如果旧记录无法恢复，请重新打开该录播再下载。
- 如果旧记录始终无法恢复，可在 Tampermonkey 菜单中清除采集记录，再重新进入课程采集。

### 脚本菜单

在 Tampermonkey 的脚本菜单中可以：

- 显示或隐藏助手面板。
- 重新扫描当前页面及其同源 iframe。
- 重新采集已经加载过的课件，同时保留录播、勾选状态和已保存计数。
- 清除采集记录并允许重新采集；当前页面中等待保存的文件不会被删除。

## 答题助手

答题功能默认关闭。进入“答题助手”页签，选择模式并填写必要配置后，点击“保存并应用”才会启用。

当前支持课堂发布的单选题和多选题；判断题按页面提供的两个选项处理。

| 模式 | 行为 |
| --- | --- |
| 随机选择并自动提交 | 从页面实际选项中随机选择，等待设定时间后提交；多选题会随机选择一个或多个选项。 |
| AI 回答后自动提交 | AI 返回有效答案后提交；超时、接口失败、无效答案或临近截止时按设置随机兜底。 |
| AI 仅显示回答 | 在面板中显示建议和简短理由，由用户在网页中手动作答，不会自动提交。 |

默认值为随机延迟 3 秒、AI 总等待 20 秒、截止前兜底 3 秒。点击“立即停用”、手动答题、老师结束题目或课堂连接关闭，会取消仍在等待的自动操作。已经发出的提交无法撤回。

提交会复用题目所在 iframe 中的网页请求客户端，以保留原网页的登录和 CSRF 上下文。只有接口明确返回 `code: 0` 才显示提交成功；结果不明或失败时不会自动重试，请检查原网页。

### AI 配置

AI 模式使用兼容 `/chat/completions` 的接口，需要填写 **API Key、Base URL、模型名称**。界面提供以下预设：

- 硅基流动：`https://api.siliconflow.cn/v1`
- 阿里云百炼（北京）：`https://dashscope.aliyuncs.com/compatible-mode/v1`
- DeepSeek：`https://api.deepseek.com`
- 本机兼容服务：`localhost`、`127.0.0.1` 或 `[::1]`

模型 ID 由用户根据账户权限填写。不同地域或工作空间的百炼服务应使用控制台给出的地址。

脚本只允许访问 `main.js` 元数据 `@connect` 和代码中 AI 域名白名单共同授权的服务商。其他自定义域名默认不可用；如需增加服务商，需要同时修改脚本头部和 `ALLOWED_AI_HOSTS`，并自行承担相应的信任风险。

### API Key 保存方式

- 默认只保留在本次页面会话中，刷新页面后需重新填写。
- 勾选“记住 API Key 到本设备”后，密钥会保存到 Tampermonkey 的脚本存储中。该存储不是加密保险库，可能被扩展备份或同步功能包含。
- 密钥与普通配置分开保存，并绑定规范化后的 AI 接口地址。更换端点后必须重新填写密钥。
- “清除密钥”会同时停用答题。

### 题目图片

题目图片上传默认关闭，需要用户主动勾选。

启用后，脚本只从雨课堂 HTTPS 图片域名读取题目图片，将图片作为内嵌数据发送给 AI，不发送课程图片签名 URL、课堂 Cookie 或课堂认证头。使用视觉模式前请确认模型支持图片输入。

AI 会收到题干、选项和用户选择上传的题目图片。请不要在不需要时启用图片上传。

## 数据与安全说明

- 远程课堂 API、课件图片、录播和 AI 服务均通过 HTTPS 访问；本机 AI 服务允许使用 HTTP。课件和录播沿用雨课堂自身的 HTTPS 传输，不额外实现自定义加密。
- 同源课堂 API 使用页面自身的登录会话，不读取 `document.cookie` 后复制到请求头。
- 课件图片和录播请求使用匿名连接，不主动携带课堂 Cookie 或 Authorization。
- 课件图片和录播地址经过协议、域名、路径或重定向校验，并检查内容类型、大小、图片尺寸或 MP4 文件结构。
- 下载状态只持久化恢复所需的课程和资源标识。带签名的播放地址、Cookie 和认证请求头不会写入网站 `localStorage`。
- AI 密钥不会进入网站 `localStorage`、运行日志、iframe 消息或课堂资源请求。
- 脚本不包含遥测、统计上报或远程代码加载。

## 配置参数

高级用户可在 `main.js` 开头的 `CONFIG` 对象中调整下载参数：

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| `MAX_WORKERS` | 12 | 当前标签页图片和录播分段请求共用的最大并发连接数。 |
| `MAX_CONCURRENT_JOBS` | 3 | 同时执行的课件或录播任务数。 |
| `VIDEO_WORKERS` | 4 | 单个录播文件的分段下载并发数，仍受 `MAX_WORKERS` 限制。 |
| `VIDEO_CHUNK_BYTES` | 8 MiB | 每个 Range 分段的大小。 |
| `MAX_RETRIES` | 3 | 临时网络错误后的额外重试次数；404 等永久错误不会重试。 |
| `RETRY_BACKOFF_MS` | 800 | 重试退避的基础间隔。 |
| `VIDEO_TIMEOUT_MS` | 600000 | 单次录播网络请求的超时时间，单位为毫秒。 |
| `SAVE_TIMEOUT_MS` | 600000 | 等待 Tampermonkey 确认保存的超时时间，单位为毫秒。 |

较高的并发会占用更多带宽和内存。浏览器需要缓存完整录播后才交给下载管理器；低内存设备建议降低任务并发数和分段并发数。

## 常见问题

### 面板没有出现

确认当前地址属于 `https://pro.yuketang.cn/*`，并检查是否处于登录页或二维码登录层。先刷新最外层课堂页；如果问题仍在，确认只启用了本项目的一个脚本版本。

### 课件列表为空

打开具体课件后查看面板中的“课件采集”状态。提示被旧记录跳过时，点击“重新采集课件”；接口已经过去且当前页面仍无法补采时，需要重新进入课件页面。

### 文件保存失败

确认 Tampermonkey 下载模式为 **浏览器 API**，脚本具有下载权限，且允许 `pdf` 和 `mp4`。如果浏览器支持文件保存选择器，也可以使用“另存为”。

### AI 请求失败

确认 Base URL 在允许列表中、模型名称有效、API Key 未因更换端点而失效，并检查目标模型是否支持所选图片模式。

### 手机或后台页面没有按时提交

浏览器后台冻结、断网或脚本管理器未及时唤醒计时器，都可能导致操作延迟。页面恢复后不会补交已过期的题目。请只在能够保持页面运行的设备上启用自动答题。
